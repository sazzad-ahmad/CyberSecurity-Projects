
# 🔐 Password Strength Checker

A Python-based Cyber Security mini project that analyzes password strength using character types and password length.

## 📌 Project Overview

This tool evaluates password strength by checking different security criteria and provides suggestions to improve weak passwords.

## ✨ Features

- Password length analysis
- Uppercase letter detection
- Lowercase letter detection
- Number detection
- Special character detection
- Password strength scoring
- Security improvement suggestions

## 🛠️ Technologies Used

- Python 3
- Kali Linux
- Git & GitHub

## 🚀 How to Run

1. Clone the repository.
2. Navigate to the project directory.
3. Run the following command:

```bash
python3 password_checker.py
```
